# Python-GO!
Python GO!

Python GO! é uma linguagem de programação experimental inspirada em Python, desenvolvida para permitir a escrita de programas em diferentes idiomas por meio de patches.

Sobre o projeto

O objetivo do Python GO! é oferecer uma experiência de programação familiar, baseada em uma sintaxe semelhante à do Python, mas com um diferencial: cada idioma é definido por um patch próprio.

Os patches contêm as palavras-chave utilizadas pela linguagem, permitindo que o núcleo do Python GO! reconheça e interprete diferentes idiomas sem precisar ser reescrito para cada um deles.

Sistema de patches

Para executar um programa, é obrigatório possuir o patch correspondente ao idioma utilizado.

Cada arquivo de programa utiliza apenas um patch de idioma, identificado no próprio código.

Exemplos de patches disponíveis:

- "PGO-EN.pgpatch" — patch de inglês.
- "PGO-PT-BR.pgpatch" — patch de português brasileiro.

Estrutura do projeto

- "python_go.py" — núcleo responsável por interpretar e executar os programas.
- "patches/" — diretório que contém os patches de idioma.
- "programas/" — diretório destinado aos arquivos de código-fonte ".pgo".

Objetivos

- Criar uma linguagem inspirada em Python.
- Permitir diferentes idiomas por meio de patches.
- Manter o núcleo independente dos idiomas disponíveis.
- Facilitar a criação, organização e execução de programas.

Estado do desenvolvimento

Versão atual: 0.1.5

O Python GO! está em desenvolvimento experimental. Seus recursos, sua sintaxe e seu sistema de patches poderão evoluir conforme o projeto avançar.

Filosofia

Uma linguagem. Vários idiomas. Um núcleo.
